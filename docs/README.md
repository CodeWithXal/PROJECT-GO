# PROJECT GO

PROJECT GO is a full-stack productivity and project management platform being built with production-quality software engineering practices.

This repository follows a monorepo architecture containing both the frontend and backend.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript (TypeScript planned)

### Backend
- Node.js
- Express.js
- MongoDB (coming soon)

## Project Structure

PROJECT-GO/
├── frontend/
├── backend/
├── README.md
└── package.json

## Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
